# 绝地潜兵2入群审核 1.1.0

问题：绝地潜兵2中你最不喜欢的战备是？发布包不预填个人群号，请先设置你管理的目标群。

每30秒检查已有和新增的普通入群申请。明确识别真实战备即可通过，不要求解释理由；支持中英文、简称及轻微错字。未识别、空答案、模糊答案、模型故障、问答读取不完整均保留人工，不自动拒绝。

适配桌面 SnowLuma 和安卓 NapCat。NapCat 的 `join_requests.invitor_uin` 实际代表申请人，不能按“有邀请人”排除。SnowLuma 只接受明确的普通申请 flag，未知格式保留人工。数值申请标识超过 JavaScript 安全整数范围也保留人工。

## 开关和设置

安卓新安装默认关闭。在“插件 → 绝地潜兵2入群审核”开启，可修改群号、5至3600秒检查间隔及AI辅助开关。桌面保留原有默认启用行为和已有用户设置。**入群审核开关独立于聊天自动回复开关**；要停止审核，关闭该插件或停止运行服务。

安卓新增经过本机控制台鉴权的只读状态接口 `/api/android/join-review`。插件页显示最近检查、管理员身份、通过/留人工次数及本插件的AI token统计；这些独立调用不冒充已加入聊天用量账本。

## 批准行为

- 使用当前 QQ HTTP 配置和 `httpToken || httpAccessToken || accessToken`，不扫描其他账号的协议配置或复制密钥。
- 每次批准前重新查询机器人权限、申请是否仍待审、申请人和答案是否未改变。
- 首次检查和定时检查串行；停用和热重载取消网络/模型任务。请求已经送达 QQ 服务端后无法撤回。
- 发出批准之前持久化尝试记录。若接口超时，结果可能已在服务端生效，因此不会盲目重试，显示“请人工核对”。
- 审核记录按登录机器人、群和原始 flag 区分。判定缓存有版本和24小时期限，AI临时故障5分钟后可再检查。
- 待审列表请求最多100条；接口未提供分页。超出协议接口可返回范围的申请不能保证全部可见。

记录保存到当前应用 `DATA_DIR/hd2-join-review.json`，安卓按账号分开。源目录不包含配置、密钥或运行记录。
