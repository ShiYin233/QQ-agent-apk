## 诊断

官方文档确认的是 Termux + proot-distro 路线。Termux 构建依赖固定前缀、libandroid-shmem、libtalloc 以及 loader 配置。不能据此声称本项目独立应用已经可运行。NapCat 许可使用非商业及修改分发限制，不能按本仓库的 MIT 许可一并处理。

Android 构建环境最初仅有 JRE，随后通过上游 SHA-256 校验安装 JDK。代理 CA 使用环境提供的可信 Java trust store，TLS 验证保持开启。SDK 归档先对照 Google 官方仓库元数据 SHA-1 校验，再记录下载产物 SHA-256。没有跳过包签名、修改组件预期哈希或使用修改版 QQ。

## 验收与后续

第一关的阻断不是“路线已被真机证明失败”；目前是实现与证据不足。必须继续补齐独立 PRoot、受校验的完整运行组件和真机连接，才能执行登录与消息验收。检查 APK 可以采集候选手机信息，但不能解除组件阻断。
