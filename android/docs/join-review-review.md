# 绝地潜兵2入群审核审查与安卓适配

审查日期：2026-10-07。插件版本：1.1.0；安卓版本：0.5.2-join-review。

按用户设置的目标群审核。规则识别优先，AI 辅助识别其次。明确识别出词库中的任意真实战备即可通过，不要求解释；其余申请保留人工，不自动拒绝。每30秒串行检查，启动时包含已有待审申请。公开源码与 APK 不预填个人群号，缺少群号时不查询或批准申请；已有用户设置仍保留。

## 修复结果

原实现的英文简称使用子串匹配，`great` 会误命中 `EAT`、`5000` 会误命中 `500`。现在为英文和数字简称增加边界，并先提取申请答案，避免仅问题中的战备名称触发批准。

原实现误把 NapCat 普通入群申请中的 `invitor_uin` 当邀请人，导致普通申请全部被跳过。适配已根据手机内实际 NapCat 源码核对；只读取 `join_requests`，邀请申请留人工。SnowLuma 只使用明确的普通申请 flag。超过 JavaScript 安全整数范围的数值申请标识留人工。

当前账号的 QQ HTTP token 按 `httpToken || httpAccessToken || accessToken` 使用，不扫描其他账号。批准前重新检查管理员权限，并重新读取申请，核对申请人、答案和待审状态。停止插件会取消后续工作；已到达 QQ 服务端的请求无法撤回。

首次检查与定时检查串行。批准发出前持久化尝试记录；请求超时或结果不确定时留人工核对，不盲目重试。词库更新会清空旧判定缓存，但保留批准尝试记录。状态按账号、群、申请 flag 区分。

AI 使用现有模型和订阅适配层，关闭思考、限制输出长度、设置超时和取消信号；结果必须是严格 JSON、有效词库标识及答案中实际存在的证据。临时调用失败不会永久缓存失败。AI 用量在插件中独立统计，没有改动原聊天用量账本。

## 安卓安装与界面

插件完整目录位于 `android/app/src/main/assets/runtime/plugins/hd2-join-review/`，运行时递归复制到手机私有运行环境的 `/opt/agent/plugins/hd2-join-review/`，保证 `lib/` 文件随安装进入手机。文件替换先写临时文件，manifest 最后复制。

插件页新增群号、检查间隔和 AI 辅助设置，以及检查状态、群身份、审核次数、AI token 数和结果不确定提醒。只读状态接口 `/api/android/join-review` 使用已有控制台鉴权。

安卓首次加载默认关闭；入群审核和聊天自动回复各有独立开关。桌面保留原有默认启用行为和已有设置。2026-10-07 的桌面副本曾完成同步与本机备份；本次公开版本的空群号调整仅针对本仓库，未改动用户的桌面安装或手机数据。

## 验证与限制

本机 Node 回归共102项通过，其中入群审核50项，包含两种协议、实际原版加载器、权限、停用、并发、人工已处理、重复批准、超时以及词库更新后的去重记录。

最终构建、签名和手机检查结果见同目录 `join-review-validation.json` 与运行目录中的验证报告。未经真实入群申请批准测试，不能将模拟流程测试声称为真实批准成功。桌面控制台在本次检查时不可连接，桌面验证限于代码和加载器测试。

待审接口一次最多返回100条，未提供分页；超出接口可见范围的申请不能保证被读取。110项词库是核对快照，中文标签含描述性翻译；未收录的新战备或俗称仍留人工。

词库来源和使用说明见插件 README。模型服务失效、机器人没有管理员权限、QQ 未连接时均保留待审。
